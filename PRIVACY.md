# Privacy

NotePal is designed as a local-only macOS desktop app.

- NotePal does not require an account.
- NotePal does not include telemetry or analytics.
- NotePal does not upload notes, todos, reminders, themes, or settings.
- User data is stored locally at `~/Library/Application Support/NotePal/notepal-data.json`.

If a future release adds any network-backed feature, this document should be updated before that release is published.
