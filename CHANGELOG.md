# Changelog

## 0.1.0-beta.2 - 2026-05-13

- Updated the Professor Tao companion image with a transparent-background asset.

## 0.1.0-beta.1 - 2026-05-13

- First public macOS beta release.
- Added the NotePal desktop companion with local notes, todos, wellness reminders, and companion themes.
- Added separate text-note and sketch-note modes so creating or deleting one type does not affect the other.
- Added local image paste support for text notes.
- Added local JSON persistence with legacy NotePet data import.

Known limitation: this beta is ad-hoc signed and not Apple-notarized, so macOS may show a first-run security warning.
